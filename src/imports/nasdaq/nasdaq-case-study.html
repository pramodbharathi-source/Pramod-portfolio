02 / Challenge

Complexity had accumulated over time

The legacy product supported a wide range of advanced workflows, but its desktop-only architecture and dense interaction model made daily work harder to navigate and the wider Back Office experience difficult for new users to learn.

01

Tied to a desktop environment

The native application depended on a specific system setup, limiting access compared with a secure browser-based platform.

02

Navigation required deep product knowledge

Nested structures and technical labels made finding the correct task category or action difficult.

03

Multiple windows divided attention

Users moved among tables, menus, details, and comments while trying to retain the context of the selected task.

04

High data volume increased cognitive load

Operations teams handle large quantities of time-sensitive information and need to distinguish what requires attention quickly.

Design question

How might we modernize a complex Back Office product while preserving the speed, information density, and control experienced users rely on?

04 / Project scope

A multi-phase product modernization

The work extended beyond one interface. We established the main web experience first, then applied the system to a growing set of operational tools and detailed financial workflows.

Phase 1 · Foundation

Core workspace and task handling

The first phase established the structure and interaction patterns required for daily operations.

  • Main application layout and split-panel behavior
  • Task assignment, comments, and contextual panels
  • Settlement and netting workflows
  • Message and reference-data access
Phase 2 · Expansion

Advanced workflows and deeper tools

The second phase expanded the system across more specialized Back Office activities.

  • Settlement instructions and transfer workflows
  • Trade, transfer, and message viewers
  • Audit history and cash-account tools
  • AI-supported fields and contextual assistance

06 / Principles

Modernize without losing operational depth

The redesign did not simplify the business itself. It made the product’s complexity easier to navigate, interpret, and act on.

01

Clarity under density

Use hierarchy, spacing, and status treatment to make large tables easier to scan without hiding essential data.

02

Context stays visible

Keep task details and collaboration close to the selected item so users can investigate without losing their place.

03

Familiarity with a purpose

Preserve recognizable concepts for experienced users while replacing desktop conventions that no longer serve them.

04

System consistency

Apply shared components and interaction patterns so each new feature strengthens the wider platform.
